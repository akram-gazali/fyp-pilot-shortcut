# Running Stage 5 on Kaggle (T4, free quota)

The GPU code has **not been run since the Stage 5 rewrite**. The first Kaggle run may need a small fix; if a cell fails, send me the last 15 to 20 lines of its log (never a token).
The notebook is `kaggle/stage5_kaggle.ipynb` (generated by `scripts/make_colab_notebook.py`; do not edit it by hand).
Free GPU quota is about 30 hours a week (Kaggle's figure; check your own quota under your profile). One full run is a few GPU hours (ASSUMED until measured).

## One-time account setup
1. Sign up at kaggle.com. Open **Settings** and **verify your phone number**: GPU and Internet stay locked until you do.
2. No Hugging Face token is needed (the model is public). The repo is public, so no GitHub token is needed either.
   If you make the repo private later: Add-ons > Secrets > add `GH_TOKEN` (a read-only fine-grained token for this repo) and tick it for the notebook. Never paste a token into a cell.

## Steps
1. **Create the notebook.** Kaggle > Create > New Notebook > File > **Import Notebook** > upload `kaggle/stage5_kaggle.ipynb` (download it from GitHub first).
   You should see 17 cells. The first line says "SIFT-VQA Stage 5 (Kaggle)".
2. **Enable the GPU.** Right panel (Notebook options / Session options) > **Accelerator** > **GPU T4 x2** (or **GPU P100** if T4 is not offered; then tell me, because our measured numbers are from a T4).
   The notebook uses only GPU 0 even in a T4 x2 session.
3. **Turn Internet on.** Same panel > **Internet** > On (needed to clone the repo and download the 7 GB model). It may ask you to confirm the phone verification.
4. **Test interactively once.** Press **Run All** (or run the cells in order) and watch the first five cells:
   - cell 2 prints a table with a Tesla T4 and "Python 3.x";
   - cell 3 prints a one-line git commit;
   - cell 4 ends with "pinned packages installed; torch left at ...". If it prints **STOP: a pin conflicts with this machine's torch**, nothing was forced: send me that output;
   - cell 5 prints library versions, then `dtype_would_be: fp16` on a T4. A line `version mismatch (...)` means a pin differs: send it to me.
5. **Prepare** (CPU, about 10 to 20 minutes): you must see `hash match with committed manifests:` with every value `True`.
6. **Dev-format** prints four lines like `suffix@224: macro ...  wrong-format ...%  ... s/item`, then `CHOSEN: <method> <resolution>`.
7. **Zero-shot, grid, cost**: each prints its result; the grid prints one dict per row (some are `OOM`: that is expected).
8. **Background run.** When step 4 worked, click **Save Version** > **Save & Run All (Commit)** > Advanced settings: keep GPU on. You can close the browser. A session limit exists (Kaggle states about 9 to 12 hours); the notebook writes each JSON as soon as it exists, so a stop loses at most the current step.
9. **Download the results.** Open the saved version > **Output** tab > download the files under `stage5_results/` (`dev_format.json`, `eval_choice.json`, `zero_shot.json`, `grid.json`, `cost_extrapolation.json`, `prepare_hash_check.json`, `env_check.json`, `env_freeze.json`, `run_meta.json`).
10. **Put them in the repo** (no data, no checkpoints, no tokens):
```bash
mkdir -p reports/stage5 && cp ~/Downloads/{dev_format,eval_choice,zero_shot,grid,cost_extrapolation,prepare_hash_check,env_check,env_freeze,run_meta}.json reports/stage5/
.venv/bin/python scripts/make_pilot_report.py
git add reports/stage5 reports/pilot_report.md && git commit -m "Stage 5 GPU results" && git push
```
Then send me `env_freeze.json`: I will add the missing pins to `requirements-gpu.txt` from it.
